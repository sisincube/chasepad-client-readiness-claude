# Discovery and evaluation prompts

These prompts cover explicit searches, natural agency language, and indirect intents that should retrieve the ChasePad skill.

## Primary prompts

1. Build a client onboarding plan from this proposal.
2. Check whether this website project is ready for kickoff.
3. Turn these discovery notes into an agency onboarding checklist.
4. What files, access, approvals, and decisions are missing before we start?
5. Create a copy-ready request for everything we still need from the client.
6. Audit this project brief for kickoff blockers.
7. Prepare our internal team and the client for the first week of this engagement.
8. Who should own each part of onboarding for this project?
9. Convert this scope of work into a tailored kickoff agenda and readiness report.
10. The client accepted our proposal. What should happen next?

## Project-specific prompts

11. Prepare onboarding for this UGC campaign, including usage rights and approval checks.
12. Audit this website redesign for content, CMS, hosting, analytics, and launch dependencies.
13. Build a retainer onboarding plan with request intake, priorities, feedback, and reporting cadence.
14. Check this video project for footage, releases, music rights, edit rounds, and delivery requirements.
15. Create a client readiness request for this paid media account without asking for passwords.
16. Turn this brand strategy brief into a kickoff plan and decision-maker map.

## Ambiguous prompts that should still match

17. Are we actually ready to start this client?
18. I keep chasing clients for files. Organise what I need to ask for.
19. We have a signed proposal but kickoff feels messy. Help me prepare.
20. Find the gaps in this client handoff.
21. Turn this loose list into a send-ready request with owners, due dates, file formats, and secure handoff methods.
22. Separate the assets we need from the copy the client still has to approve.

## Negative prompts

These should not invoke the skill unless the user connects them to client onboarding or pre-kickoff readiness:

- Write a generic project plan for my personal goals.
- Summarise this document.
- Create an employee onboarding programme.
- Build a customer support FAQ.
- Diagnose why my server is slow.
- Make a social media calendar without a client onboarding context.

## Evaluation expectations

For relevant prompts, the result should:

- choose the correct mode;
- use all eight readiness categories;
- name critical blockers conservatively;
- distinguish source facts from recommendations;
- adapt to the project type;
- produce both internal and client-facing actions in combined mode;
- use secure access language;
- generate a tactful, specific client request;
- preserve known owners, due points, requested formats, and secure handoff methods;
- never claim a direct ChasePad handoff exists in phase one.
